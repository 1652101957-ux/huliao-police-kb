# 大埔县湖寮派出所 · 新警个人知识库

> 生成日期：2026-08-26　|　数据来源：公开网络资料 + OpenStreetMap（ODbL）

本文件夹是「湖寮派出所新警知识库」插件（hulia-1）的数据源。插件运行时会从本文件夹加载数据并显示在 DeepSeek Harness 界面中（会话头部「📚 湖寮知识库」按钮）。

## 文件说明

| 文件 | 内容 | 可否编辑 |
| --- | --- | --- |
| `kb-meta.json` | 概况、派出所信息、数据来源 | 可编辑 |
| `kb-learning.json` | 30 日入职学习计划（4 周，每日：学习内容/自测/产出） | 可编辑 |
| `kb-customs.json` | 风俗民情（客家话、节庆、红白喜事、饮食、警务提醒、县情人文） | 可编辑 |
| `kb-locations.json` | 常用地理位置（机关/医院/学校/车站/公园/市场/银行/村社区/桥梁，含坐标） | 可编辑 |
| `kb-beats.json` | 辖区 7 大片区档案（范围/道路/单位/治安要点）+ 外围村组 | 可编辑 |
| `kb-alleys.json` | 老城区命名巷道清单 + 踏勘方法 | 可编辑 |
| `kb-hotlines.json` | 应急与常用联系电话 | 可编辑 |
| `kb-tips.json` | 新警入职提示卡 | 可编辑 |
| `osm-mapdata.json` | 辖区地图底图（629 条道路、8 条水系、242 个 POI，米制投影坐标） | 建议勿改 |
| `osm-streets-raw.json` / `osm-pois-raw.json` / `osm-places-raw.json` | OpenStreetMap 原始数据（2026-08-26 采集） | 只读存档 |
| `progress.json` | 打卡/笔记/报到日进度（插件自动读写） | 插件自动管理 |

## 使用方法

1. 在 DSH 会话头部点击「📚 湖寮知识库」按钮打开面板。
2. 面板包含 7 个页签：
   - **今日学习**：设置报到日，自动显示当天的学习内容，可打卡、记笔记；当天有配套视频时显示「推荐学习视频」；
   - **30日计划**：按周查看全部 30 天任务，每天含推荐学习视频（B站/央视网，点击新窗口播放）；
   - **辖区地图**：高德风格可视化地图——图标化地点标识（⭐派出所 🏥医院 🎓学校 🚌车站 等 50 种）、点击弹出信息气泡（地址/电话/备注）、比例尺、指北针、缩放/全景/回镇中心控件、视野信息条、图例；支持图层开关、搜索定位、拖动平移、滚轮缩放；
   - **片区档案 / 常用地点 / 风俗民情 / 应急电话**：对应知识内容。
3. 在对话框中直接提问也可查询知识库（如「今天学什么」「泰安楼在哪」「清明防火注意什么」），学习任务会附带推荐视频链接。
4. 编辑任意 `kb-*.json` 后刷新页面（或重启插件）即可生效——本知识库就是你的个人档案，可以持续增补。

## 重要说明

- **地图数据**：道路/水系/POI 几何来自 OpenStreetMap（ODbL 许可），2026 年 8 月采集，坐标已投影为相对湖寮镇中心（24.358°N, 116.688°E）的米制网格。
- **片区多边形为示意图**：按社区与地理分布绘制，用于新警熟悉辖区方位；实际警务区划、责任区划分、巡防线路以派出所正式安排为准。
- **派出所位置**（西环路 411 号）为按门牌号沿西环路推算，请现场核实后可在 `kb-locations.json` 中修正。
- 风俗民情、治安要点为公开资料整理的学习参考，涉及执法依据的请以现行法律法规和所内规范为准。
- 打卡与笔记保存在 `progress.json`（DSH 插件）或浏览器 localStorage（网页版），互不影响；如需重置，删除对应记录即可。

## 🌐 GitHub Pages 部署（随时随地查看）

本文件夹自带一个**纯静态网页版**（`index.html` + `assets/`），部署到 GitHub Pages 后，手机/平板/任何电脑的浏览器都能直接访问，无需安装任何东西。

### 首次部署步骤

1. **注册 GitHub**（若没有账号）：https://github.com 免费注册。
2. **新建仓库**：右上角 `+` → New repository → 填仓库名（如 `huliao-police-kb`）→ 选 **Public**（公开，免费）→ Create repository。
3. **上传文件**：把本文件夹**内所有内容**上传到仓库。两种方式任选：
   - **方式 A（网页上传，最简单）**：在仓库页面点 `Add file → Upload files`，把本文件夹里的文件拖进去（可一次拖多个文件，注意保持 `assets/` 子文件夹结构；网页上传不支持文件夹时，可先在仓库点 `Add file → Create new file` 输入 `assets/.keep` 创建目录，再逐个上传）。
   - **方式 B（命令行，推荐）**：
     ```
     cd D:\deepseek\湖寮派出所知识库
     git init
     git add .
     git commit -m "湖寮派出所新警知识库"
     git branch -M main
     git remote add origin https://github.com/你的用户名/仓库名.git
     git push -u origin main
     ```
4. **开启 Pages**：仓库 `Settings` → 左侧 `Pages` → Source 选 **Deploy from a branch** → Branch 选 **main** + 目录 **/(root)** → Save。
5. **等待 1~2 分钟**，访问：
   `https://你的用户名.github.io/仓库名/`
   例如 `https://zhangsan.github.io/huliao-police-kb/`

### 更新内容

修改任意 `kb-*.json` 后重新上传/推送即可，线上 1~2 分钟后自动更新。

### 网页版功能

- 今日学习（报到日设置、打卡、笔记，保存在浏览器本地）+ 新警提示
- 30 日计划（周折叠、视频链接直接播放）
- 辖区地图（SVG 渲染，支持缩放/拖动/搜索/气泡/图层开关，触屏可用）
- 片区档案 / 常用地点（可跳转地图定位）/ 风俗民情 / 应急电话
- 深色主题，手机端自适应

### 注意事项

- **不要用「双击打开 index.html」的方式本地预览**——浏览器安全限制会禁止读取本地 JSON；请部署到 GitHub Pages，或在本地用 `python -m http.server` 之类的静态服务器预览。
- 仓库设为 Public 时，任何知道链接的人都能看到内容（不含涉密信息，均为公开资料整理）。
- 若提示 `progress.json` 不需要上线，可在上传时跳过该文件（网页版用浏览器本地存储）。
